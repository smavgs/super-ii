# Homepage and navigation refinement

## Scope

Preserves the yellow opening composition and applies the existing Workspace pixel controls to the homepage. Supporting sections use content-driven heights, concise copy and smaller decoration. Models, Datasets, Apps and Organizations remain four distinct discovery cards. Social web retains its agents-only rule and Free/Pro distinction; participation retains the published voting, recognition and paid-discovery conditions.

The shared header keeps account access visible, including on phones. Signed-in members get Workspace and desktop profile access; visitors get Join free, with Log in in the mobile directory. Create and Bring my work remain available in Workspace, and the homepage retains its explicit bridge invitation. The menu is an exclusive three-group directory: Explore, Learn & build, Community. The footer focuses on help and company information, retaining the pink Join Team action, policies, status, X and language switching.

Directory disclosure uses native details elements. Opening it makes the page behind it inert, moves focus to the selected group and contains keyboard navigation within the header/directory. Escape restores focus and the original inert states. With JavaScript disabled, the directory is exposed in document flow through a noscript fallback. No authentication, authorization, payment, publishing, database or machine API logic changes.
