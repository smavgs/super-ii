# Public discovery Workspace styling

Implementation and local verification, 18–19 October 2026. Production deployment is a separate release step.

## Scope

Eight requested entry points: `/models`, `/datasets`, `/spaces`, `/transparent`, `/builders`, `/robot`, `/collections`, `/organizations`.

- Shared compact heading, pixel mascot, tactile yellow/cyan/violet actions and an eight-destination Explore switcher. Existing global navigation and individual detail pages remain available.
- Catalog search/sort first; optional filters and technical detail disclosures. Reviewed and externally linked cards remain distinct. Active promotions retain their separate rail; an empty promotion area becomes an optional disclosure.
- Directories first, with optional collection creation and team guidance. Collection addresses are suggested from titles and remain editable. Anonymous visitors receive an explicit sign-in/join route before entering creation details.
- Transparent keeps its four evidence labels visible and makes explanations and agent instructions optional. Failed report retrieval is labeled unavailable rather than shown as an empty result.
- Robot has one selected working area at a time, including personal work where authenticated. The existing planner, results, save flow, component references, public directories, agent contracts and access levels remain present.
- Small related fixes: blank numeric GET filters are absent rather than zero; collection address patterns are valid under the browser's Unicode sets flag; builder filtering explains a local zero-match result.
- English, Russian and Simplified Chinese interface additions; authored content and technical identifiers remain source text.

No database migration, API contract, execution service, billing change or entitlement change. Robot planning and report/collection persistence still use their existing APIs. No new runtime dependency.
