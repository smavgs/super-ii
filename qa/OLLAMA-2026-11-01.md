# Curated Ollama catalogue — 1 November 2026

## Delivered behavior

The approved AILocalClick catalogue supplies 266 external model listings under `@smavgs`. Visitors can open an existing-style Super ii model page, inspect its source card and files, choose a version, and download an upstream file with its proper filename. The curator owns the listing, not the underlying model. Authors, source links and source licenses remain visible. The existing Hugging Face Bridge and reviewed hosted repositories retain their own publication boundaries.

The source snapshot resolved standard weight layers for 241 model families. The other 25 listings retain their actual source availability; no local-download promise is added to cloud-only or unsupported sources. Super ii streams files from the allowlisted Ollama infrastructure, without storing weights. The main button downloads the selected weight file; it does not install the model into Ollama. Companion files and the optional complete Ollama command are available separately.

## Verification boundaries

No full multi-gigabyte model transfer, sustained throughput test, model execution, or every possible model/version/runtime combination is claimed. Upstream availability and license terms remain source-dependent. Displayed hashes are source metadata, not proof that Super ii scanned the weights. Streaming traffic passes through Super ii even though weights are not stored. Automated ownership claims/transfers and a new self-service Ollama import form are outside this release.
